스페인어 공부 통합 검색 (단어장 + 부사 + 내추가)

단어장/부사 파일을 함께 검색하고, 새로 배운 단어는 내추가로 로컬 저장할 수 있습니다. 저장된 단어는 나중에 엑셀(.xlsx)로 내보낼 수 있어요. (생성: 2026-03-21 07:03)
초기 포함: 단어장 + 부사
⚠️ 이 HTML과 같은 폴더에 xlsx.full.min.js 파일이 있어야 엑셀 불러오기/엑셀 내보내기가 됩니다.
총 개 표시 개 내추가 개 저장: 로컬 TIP: 공백으로 여러 단어를 넣으면 모두 포함(AND) 조건입니다.
• 단어 추가는 브라우저의 localStorage에 저장됩니다. 같은 기기/같은 브라우저에서는 다시 열어도 남아 있습니다.
• 참고값(참고01~04)은 마지막 저장값을 기억해서 다음 입력 때 바로 복사할 수 있게 했습니다.
• 내추가 단어는 별도 관리표 대신 메인 검색 결과 표에서만 보이고, 맨 앞 구분 열에 내추가로 표시됩니다.
• 내추가 행의 맨 오른쪽 수정/삭제 버튼으로 바로 편집할 수 있습니다.
• 내추가 단어만 별도 엑셀로 내보낼 수 있습니다.
• 현재 상태 HTML 내보내기를 누르면, 지금까지의 추가/수정/삭제 상태가 반영된 공유용 HTML 원문이 준비됩니다. HTML Viewer Q에서는 여기서 새 문서로 열기 또는 HTML 복사를 쓰는 방식이 가장 안정적입니다. 내보내기 화면이 바로 닫히던 문제도 함께 보정했습니다.
• Ctrl+1 또는 ⌘+1 를 누르면 단어 추가 창이 바로 열립니다. 입력칸에 커서가 있어도 동작합니다.
